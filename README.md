# AI Vision Portfolio — HTML, CSS & JavaScript

A responsive, dark industrial-AI portfolio built with plain HTML, CSS, and JavaScript. No build tools or frameworks are required.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — responsive styling and illustrative vision UI
- `script.js` — mobile navigation, project detail dialogs, contact links, and copy-email action

## Before publishing
1. Open `script.js`.
2. Replace `YOUR_EMAIL@example.com` with your public contact email.
3. Replace the LinkedIn and GitHub placeholder URLs with your actual profile links.
4. Review all project descriptions. Keep only claims that match your real experience and replace illustrative visuals with approved screenshots or demo videos where possible.
5. Open `index.html` in your browser to preview the site.

## Publish using GitHub Pages
1. Create a GitHub repository, for example `ai-vision-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will be shown in **Settings → Pages**.

This is a static website, so it can be hosted directly by GitHub Pages. Do not put API keys, passwords, or private server credentials in these files.
